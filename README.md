# Kelvann Group Corporate Website

A responsive Next.js + Tailwind CSS implementation based on the provided Kelvann Group UI reference.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Main files

- `app/page.tsx` — page structure/content
- `app/globals.css` — custom styling and responsive rules
- `app/layout.tsx` — metadata/layout
- `package.json` — dependencies and scripts

## Customization

Replace the Unsplash URLs in `app/page.tsx` and `app/globals.css` with the company's real images/logos before production deployment.
